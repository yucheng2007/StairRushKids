# Stair Rush Kids

Stair Rush Kids 是一款原創、可愛簡約風格的靜態網頁小遊戲。玩法靈感來自經典的「下樓梯」生存挑戰，但所有角色、平台外觀、UI 與效果皆為原創幾何風格，未使用任何受版權保護素材。

## 專案特色

- 純前端：HTML + CSS + JavaScript
- 無後端、無資料庫
- 直接開啟 `index.html` 即可遊玩
- 使用 `canvas` 繪製遊戲畫面
- 支援桌機鍵盤與手機觸控
- 分數與最高分（`localStorage`）
- 遊戲狀態：`start` / `playing` / `paused` / `gameOver`

## 遊戲玩法

1. 控制小朋友角色左右移動，持續踩平台生存。
2. 角色會受到重力影響往下掉落。
3. 平台會持續生成，速度與難度隨分數提升。
4. 避開危險平台、避免掉出畫面。
5. 生命值預設 3 點，歸零則遊戲結束。

## 平台種類

- **普通平台（綠色）**：安全站立。
- **破裂平台（黃色）**：踩到後短時間消失。
- **彈跳平台（藍色）**：提供向上彈跳。
- **危險平台（紅色）**：踩到會扣生命。

## 操作方式

### 桌機

- `←` / `A`：向左移動
- `→` / `D`：向右移動
- `P`：暫停 / 繼續
- `Space`：開始（在開始或結束畫面）

### 手機

- 觸控畫面左半邊：向左移動
- 觸控畫面右半邊：向右移動
- 放開手指：停止移動

## 本機執行

### 方式一（最簡單）

直接用瀏覽器開啟 `index.html` 即可。

### 方式二（建議）

使用任意靜態伺服器（避免部分瀏覽器本機限制）：

```bash
# Python 3
python -m http.server 8080
```

開啟 `http://localhost:8080`。

## 部署到 GitHub Pages

1. 將專案推送到 GitHub Repository。
2. 進入 Repository 的 **Settings** → **Pages**。
3. 在 **Build and deployment** 中：
   - Source 選擇 **Deploy from a branch**
   - Branch 選擇 `main`（或你的分支）與 `/ (root)`
4. 儲存後等待部署完成。
5. 取得 `https://<你的帳號>.github.io/<repo>/` 網址即可遊玩。

## 可擴充方向

- 新增道具（護盾、加速、回血）
- 角色外觀自訂（純程式幾何造型）
- 音效開關與背景音樂（自製素材）
- 更多地圖主題（森林、星空、糖果）
- 排行榜（可串接雲端服務）

## 檔案結構

- `index.html`：頁面結構與 HUD/UI
- `style.css`：可愛簡約風格 UI 與排版
- `game.js`：遊戲主邏輯（玩家、平台、碰撞、分數、狀態、輸入）
- `README.md`：專案與部署說明
